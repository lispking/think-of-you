## 本地复现

```sh
# 需要环境变量 MIMO_API_KEY (小米 MiMo 开放平台, TTS 当前限时免费)

# 1) 渲染 900 帧（约 3–5 分钟）
python3 video/render.py

# 2) 生成音轨（旁白走小米 MiMo TTS + 垫乐 + 音效）
python3 video/make_audio.py --probe   # 先看每句旁白时长是否压到下一镜
python3 video/make_audio.py --force   # --force 会重调 TTS 重生成旁白

# 3) 合成成片（画面已渲染好时，配音可只换音轨不重编码）
cd video && ffmpeg -i frames/f%05d.png -i audio/mix_novoice.wav \
  -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -shortest out/无配音.mp4
ffmpeg -i out/小聆时钟天气番茄钟_无配音.mp4 -i audio/mix_voice.wav \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest out/配音版.mp4
```

依赖：`python3` + `numpy` + `Pillow`、`ffmpeg`、`afconvert`（macOS 自带）、
小米 MiMo `MIMO_API_KEY`。
中文字体用本机 `LXGWWenKai`（霞鹜文楷），时钟数字用 `SFNSMono`。

换音色：改 `video/make_audio.py` 顶部的 `VOICE`（可选 `冰糖 / 茉莉 / 苏打 / 白桦`）
与 `STYLE`（自然语言风格指令），单句试听可跑：

```sh
python3 video/tts_mimo.py --say "要试的文本" --out /tmp/a.wav --voice 冰糖
```
