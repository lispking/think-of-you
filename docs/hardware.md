# 设备能力与限制

这个应用是贴着设备的边界写的，所以先看清楚边界在哪里。
以下能力以 **Mini 固件 3.0.2 及以上**为准（实测固件 `3.0.2-5f2bb183`）。

## 硬件

| 项 | 值 | 说明 |
| --- | --- | --- |
| 屏幕 | 240 × 240 | RGB565，颜色会量化 |
| 按键 | **1 个**：`function`（功能键） | 只声明 `click` 事件；长按 ≥3000ms 属系统操作，**不产生点击事件** |
| 指示灯 | **1 个**：`status`，单色 | 只能亮、灭、闪；不能指定颜色 |
| 扬声器 | 有 | 蜂鸣与 TTS 共用 |
| 麦克风 | 硬件有（`microphone: true`） | **但 Lua 侧没有音频输入接口**，应用用不上 |
| 网络 | 有 | 见[协议](protocol.md)：只能主动轮询 |

按键、灯、屏幕这几项来自 SDK 里 Mini 的设备配置（`simulator/profiles/mini.json`）；
麦克风同理——它在硬件声明里为 `true`，但公开的 API 模块里没有任何录音接口。

## 屏幕绘制

只能画**填充矩形**和**文字**，没有图像接口。

| 限制 | 值 |
| --- | --- |
| 每帧矩形数 | ≤128 |
| 每帧文字段数 | ≤8 |
| 单段文字长度 | ≤63 字节（UTF-8；一个汉字通常 3 字节） |
| 文字坐标 y | ≤ `app.height - 16`，即 ≤224 |
| 名义字号 | 16px（实际行距与字宽由字形决定） |

- 文字**永远在矩形之上**，即使 `screen.rect()` 在 `screen.text()` 之后调用。
- 240px 宽、16px 字号，一行大约只放得下 14 个汉字——排版要按这个来数。
- 所以那株植物是一块块矩形拼的，画面里也没有任何图片资源。

## Lua 运行环境

Lua 5.4，但被削得很干净：

- **可用**：基础函数，以及 `table`、`string`、`math`、`utf8`。
- **不可用**：`io`、`os`、`package`、`debug`、`coroutine`、动态加载、文件、原始套接字；
  还有 `collectgarbage`、`dofile`、`load`、`loadfile`、`print`、`warn`、
  `pcall`、`xpcall`、`setmetatable`。
- 源码上限 **64KB**，必须是文本，不接受 Lua 字节码；单实例 Lua 堆 **384KB**。
- 源码执行预算 500,000 条指令（约 150ms），回调 250,000 条（约 500ms）。
  所以回调要短：把动画进度存进变量，在后续 tick 里推进。

没有 `pcall` 意味着**参数非法会直接终止应用**，所以所有外部数据都要先校验类型与范围
（应用里对存档、消息体、对手参数都做了逐项检查）。

## API 模块

| 模块 | 用途 | 最低 API 版本 |
| --- | --- | --- |
| `app` | 查询 API 版本和画布尺寸 | 2 |
| 生命周期 | `on_start` / `on_tick` / `on_exit` | 2 |
| `input` | 接收按键点击 | 2 |
| `screen` | 绘制矩形与文字 | 2 |
| `led` | 控制指示灯 | 2 |
| `buzzer` | 播放蜂鸣音 | 2 |
| `clock` | 读取日历时间（**秒**精度） | 3 |
| `storage` | 保存应用数据 | 3 |
| `http` | 异步 HTTP 请求（只有 GET / POST） | 4 |
| `json` | 编解码 JSON | 4 |
| `tts` | 文本播报 | 4 |

关键额度：

| 接口 | 额度 |
| --- | --- |
| `http` url | ≤511 字节 |
| `http` headers | ≤16 项、累计 ≤1024 字节 |
| `http` body | ≤8192 字节 |
| `http` 超时 | ≤60000ms |
| `http` 响应体 | 默认 8192，最多 32768 字节 |
| 未完成请求 | ≤4 个 |
| `buzzer` | 单音 100–5000Hz、20–3000ms，**队列只有 4 格，满了丢弃** |
| `led.blink` | 亮/灭时长各 10–5000ms |
| `tts` | 正文 ≤512 字节，同时只允许一个，**不排队**，启动阶段禁止调用 |
| `storage` | ≤32 项、≤1024 字节；键 ≤32 字节；值为有限数字/布尔/≤256 字节字符串，**不支持嵌套**；同一槽写入间隔 ≥10 秒 |

## 因此做不了什么

- **录音、语音留言**：麦克风在，接口不在。
- **显示图片、图标、二维码**：只有矩形和文字。
- **彩色灯效**：指示灯单色。
- **实时推送 / 秒级往返**：只能轮询，延迟以轮询间隔计。
- **同时装多个应用**：上传即替换当前应用，所以玩法只能合进一个脚本。

## 两个实测踩到的坑

1. **源码只存在设备内存里。** `adb push` 上传的应用不会留在闪存，
   设备重启后必须重新上传；`storage` 里的数据会保留。
2. **同一批设备的 ADB 序列号可能相同。** 两台一起插上时 `adb -s <序列号>` 会歧义甚至选错设备，
   必须用 `adb -t <transport_id>` 区分。`flash.sh` 已经自动处理这一点。
